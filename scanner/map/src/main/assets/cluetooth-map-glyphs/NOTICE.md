# Bundled map glyphs

`noto-sans-bold/0-255.pbf` is the "Noto Sans Bold" glyph range 0-255 exactly as OpenFreeMap serves it
(`https://tiles.openfreemap.org/fonts/Noto%20Sans%20Bold/0-255.pbf`, SHA-256
`f60ce4cb899455c2203bd8293b550394ade53ffce8032bf9cc7f59255e49259c`). It covers every character the map's own labels
use: cluster and cell counts (`point_count_abbreviated`) and the route's Start and End.
