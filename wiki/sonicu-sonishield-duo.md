# Sonicu SoniShield Duo

## Identification and use

The sanitized name pattern `SonicuDuo_<suffix>` supports a SoniShield Duo
environmental-monitoring family lead. Sonicu documents use cases including
temperature/humidity monitoring for cold-chain storage, laboratories, and
facilities. A name alone does not reveal attached probes, measurements, alarm
settings, or what is being stored.

Sonicu's display-pairing guide explicitly uses the mobile app's
“Scan for SonShield Meters (BLE)” flow and pairs a display to a meter. BLE thus
has a documented local setup/display role; the Duo's configured network is the
upload path. The saved discovery is not a capture of sensor readings or a
verified cloud session. No hospital installation or ownership is established.
